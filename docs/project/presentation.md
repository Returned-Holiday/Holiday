- 제출: ppt + pdf, 슬라이드마다 하단(노트)에 발표 스크립트. 시연영상은 장표에 넣고, MP4 원본은 발표자료 폴더에 함께 업로드

- 초안: `반납한연휴_발표자료_초안.pptx`(현서). 12장 모두 스크립트 포함

## 핵심 메시지

> 유출 사고 직후 필요한 건 더 많은 정보가 아니라 **믿을 수 있는 정보와 내 상황에 맞는 조치**다. 우리는 공식 발표만으로 조치를 순서대로 알려 주고, 그 서비스 자체가 새 유출 경로가 되지 않도록 약점이 생길 자리를 설계에서 없앴다.

개발 부문(창의성·적용성·완성도)은 01~03에서, 보안 부문(약점 수·조치율·구조적 설계)은 02 후반과 04에서 답한다.

## 스토리 흐름

문제(왜 필요한가) → 해결(무엇을 만들었나) → 기능 3개 → 보안 설계·아키텍처 → 시연 → 점검 결과 → 기대효과
